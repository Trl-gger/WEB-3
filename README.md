# WEB — 3rd Year

Exercises and mini-projects from my 3rd year WEB class. 
This is where we moved on from HTML/CSS and started learning JavaScript properly.

Each folder is named by date and topic.

---

## What's in here

- **DOM manipulation** — selecting, modifying, and reacting to elements on the page
- **Form handling** — reading and validating form inputs with JS
- **BMI Calculator** — basic input/output, conditionals
- **Compound interest calculator** — math, rounding, `.toFixed()`
- **Reminder app** — working with lists and dynamic DOM updates
- **Arrays & dictionaries** — loops, array methods, objects
- **Triangle solver** — logic, conditions, geometry
- **Largest number finder** — array iteration exercise
- **STRATUS** — weather app built with the Open-Meteo API, the main project of the year

---

## Stack

Plain HTML, CSS, and vanilla JavaScript. No frameworks, no libraries.
